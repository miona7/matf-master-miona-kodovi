# 🎓 Miona – MATF Master's Code Repository

This repository contains a collection of code, projects, and research work completed during my master's studies at the **Faculty of Mathematics, University of Belgrade** 📚.  

It includes advanced coursework, practical implementations, and independent research projects focused on specialized areas of computer science, building upon the foundations laid during my undergraduate degree 🧠.

The goal of this repository is to track my academic progression and keep all my master-level code neatly organized in one place 🗂️.

---

## 📂 Structure

The repository is organized by courses and programming languages:

- **Konstrukcija i analiza algoritama 2** – C++     
  Focuses on advanced algorithms and data structures, randomized algorithms, approximation techniques, and parallel execution.
  
- **Automatsko rezonovanje** – C++, Haskell      
  Covers formal logic, SAT and SMT solving, resolution techniques, and practical applications of automated theorem proving.
